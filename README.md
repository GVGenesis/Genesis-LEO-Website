# Genesis LEO CAD

Website (public handbook + penal codes + Discord-login LEO CAD) with the Public Service role-checker bot running inside it.
Economy commands stay in gvrg.py. This project does not touch them.

Upload the CONTENTS of this folder to the root of your GitHub repo (app.py must be at the top level).
Then follow the setup steps in the chat, or see `.env.example` for the variables to set on Render.
Add penal codes to `data/penal_codes.json`: {"code":"101","title":"Offense","category":"Traffic","fine":500,"jail_minutes":0,"severity":"Low"}
